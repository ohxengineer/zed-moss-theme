# Moss for Zed

A calm, dark green theme for [Zed](https://zed.dev), ported from the **Moss** theme of
[Herdr](https://herdr.dev).

It ships two variants:

| Theme | Code colors |
|---|---|
| **Moss** | Soft pastels taken from Moss's own terminal palette |
| **Moss Gruvbox** | Gruvbox's syntax mapping, each color blended 50/50 with Moss's matching hue, plus rose keywords and cursor |

Both share Moss's editor, panel and terminal colors.

## Install

In Zed: `Cmd+Shift+X` → search **Moss Theme** → Install, then pick **Moss** or
**Moss Gruvbox** with `Cmd+K Cmd+T`.

Manual install: copy `themes/moss.json` into `~/.config/zed/themes/`.
